# Loogle Stuff

This project is a recreation of Loogle made by Walter and Severen. Click [here](https://loogleofficial.com) to visit loogle. Loogle 1.6 is the latest version that they have made and it is my goal to make more updates and add more features like what has been happening to the original loogle. I will not add more nouns / verbs / layouts for the sake of keeping savecodes compatible between loogle official.
